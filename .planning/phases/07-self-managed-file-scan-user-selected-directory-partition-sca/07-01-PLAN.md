## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → scan walk | User-selected roots (untrusted directory trees; may contain symlinks/junctions, deep paths, huge trees, ACL-locked dirs) cross into WinDirectoryWalk/FileIndex |
| index file ↔ app | `%APPDATA%\TID\wisp\wisp-index.dat` is user-writable and may be corrupt/truncated/tampered between runs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
