# Phase 6 — UI Design Contract (Tray, Settings, Autostart & Packaging)

> Visual and interaction contract for the **resident-citizen pass**: tray menu restructure (Settings action), the settings window (hotkey capture row, accent picker with swatches + custom dialog, autostart toggle), and the user-facing copy for the NSIS installer. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Qt adaptation note:** this is a Qt6/QML desktop app, not web. Tokens are logical pixels (Qt PMv2 handles DPI), typography is Segoe UI Variable (Windows-native), colors are hex, the component library is project-authored QML, Registry Safety is N/A (no component registries in Qt). This contract **extends** the Phase 1 baseline (01-UI-SPEC.md) and the Phase 5 polish contract (05-UI-SPEC.md) — geometry, core colors, typography, animation, and accent-derivation contracts from those phases remain locked and are restated only where they change.
>
> **Source of truth:** all decisions below trace to 06-CONTEXT.md (D-01..D-16, locked), the 06-DISCUSSION-LOG.md user choices, `.planning/STATE.md` (Qt 6.11.1, INI at `%APPDATA%\TID\wisp\wisp.ini`, controller-owned policy, `src/win/` firewall), and the existing `qml/Theme.qml` token singleton. Zero literal values may enter QML — every new color/spacing/duration ships as a Theme.qml token first (01-UI-SPEC token-only rule). The one shipped-literal debt (`#E5484D`, radius 6, 36px wells in HotkeyCaptureDialog.qml, Phase 2 — no UI-SPEC existed) is **tokenized this phase**.

Locked from Phase 1/5 — **unchanged sizes, weights, and line heights**. Family: `Segoe UI Variable` → `Segoe UI`. Exactly two weights: regular (400), semibold (600). No new sizes this phase.

| Role | Size | Weight | Line Height | Usage |

**Tray menu exception (declared, one surface only):** the tray context menu is a native Qt Widgets `QMenu` (D-02.2 — Widgets boundary) and uses the **system menu font and metrics** (Windows convention, like PowerToys Run). Settings text rules:
1. Row labels never switch to 600 when focused/active — 600 is reserved for the header and keycap values (no remeasure churn).
2. No wrapped text: hints and descriptions are single-line, elided right if overflow (they won't at 448 − 2×24 − control widths).
3. The hotkey value renders in a fixed-width well — a longer combo (e.g. "Ctrl+Alt+Shift+F1") must elide, never reflow the row.

## Animation & Motion Contract

Phase 1 open/close contract (launcher) is **untouched**. Phase 5 micro-animation discipline (opacity-only, `animFade`) extends to the settings surface:

| Property | Duration | Easing | Notes |
|----------|----------|--------|-------|
| Settings window open | **120ms** (animFade) | Linear (opacity only) | Fade 0→1 on show; no scale — settings is a tool window, not the showpiece. Cheap, in keeping with "instant" |
| Settings window close | **none** | — | Hide immediately on Esc/click-away (tool-window semantics; the launcher's 140ms close animation is its own identity — do not copy it here) |
| Toggle knob slide | **120ms** (animFade) | Linear | `Behavior on x` — knob slides between off/on; opacity never animates on the track |
| Swatch apply | **none** | — | Live apply must read as instant (D-06); no flash, no fade, no scale on the ring (Phase 5 D-09 discipline: selection is final form, no entrance animation) |
| Custom color dialog open | **none** | — | Instant show + focus, same as the shipped capture dialog (modal grab needs immediate paint) |

Hard rules:
1. Animate **only opacity and the toggle knob's x**. No blur, no scale, no geometry animation in either new window.
2. The settings window never animates on close and never plays the launcher's open/close animations — separate window, separate identity.
3. No animation on row hover (hoverBg snaps), no animation on the swatch ring position (snaps between swatches).

## Interaction Contract

| Interaction | Contract |
|-------------|----------|
| Open settings | **Tray → Settings only** (D-04 — no affordance in the launcher window). Controller shows the window: center → fade-in (120ms) → `requestActivate`; first focus on the hotkey row |
| Close settings | Esc → instant hide; click-away → deactivation-hide with ~150ms grace, **exempt when the new active window is the launcher** (D-04); hide preserves state |
| Hotkey row | Click well (or row) → opens the **existing** fullscreen `HotkeyCaptureDialog` unchanged (D-03, `open(currentSequence)` + `accepted` contract). On accept → `HotkeyManager::setHotkey` re-registers immediately (success criterion 3) and the well's value updates. Validation/rejection (F12, modifier-only) and conflict notification stay exactly as shipped (tray balloon + red labels — now the tokenized `danger` color) |
| Accent swatch | Click swatch → `SettingsStore.setAccent(color)` → persist-before-notify → `accentChanged` → `Theme.accent` live (Phase 5 wiring); ring snaps to the new selection; tray disc repaints (accent-aware icon). No Save button (D-06). Keyboard: Tab focuses the strip, ←/→ move selection, Enter/Space applies |
| Custom color | Click "Custom…" → staged dialog (above); OK commits, Cancel/Esc discards |
| Autostart toggle | Click (or Space when focused) → writes/removes quoted HKCU Run key (`"<exe>" --autostart`, D-12); state read when settings opens (D-10); knob slides 120ms. Write/remove failure → silent (D-16 discipline — no error toast; the toggle reflects the operation's outcome) |
| Tray menu | Native QMenu, **order locked: Open wisp / Settings / Change hotkey… / separator / Quit** (D-03). Settings action → open settings window; Change hotkey… → capture dialog (unchanged); Quit → `QCoreApplication::quit()` (D-02.1, the only exit) |
| Tray icon | 16px generated disc, **fill live-bound to accent**, white bold "w"; repainted on accent change; no asset |
| Second instance | Mutex detected → first instance **shows the launcher window** (D-09 — not settings, not a toast); second instance exits silently. No UI surface |
| Autostart boot | `--autostart` → resident, window hidden, tray present (D-11); hotkey summons the launcher |
| Keyboard (settings) | Tab order: hotkey row → swatch strip → Custom… → toggle; Esc closes (window level); Enter/Space activate the focused control; arrow keys move the swatch selection; never steal keys from the launcher (separate windows) |
| Hover | Row wells hover → `hoverBg`; "Custom…" hover → textPrimary; never accent (reserved list) |
