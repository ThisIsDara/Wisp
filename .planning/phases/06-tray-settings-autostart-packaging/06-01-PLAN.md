<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app → HKCU Run key | AutostartManager writes a registry value read by Windows at sign-in; value content crosses a trust boundary into the OS shell |
| second instance → first instance | Any process in the session can SetEvent on the named show event (session-local namespace) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | AutostartManager::setEnabled Run-key value | mitigate | Value is `"` + `QCoreApplication::applicationFilePath()` + `" --autostart"` — path from Qt, never user input; quotes enforced by construction (D-12). HKCU only, never HKLM |
| T-06-02 | Spoofing | WinSingleInstance named event | accept | Session-local `Local\` namespace (A2); worst case a same-session process pops the launcher window — nuisance only, no elevation, no data access |
| T-06-05 | DoS | WinSingleInstance named mutex | accept | Name collision with another app's mutex → second instance exits silently (benign failure mode, no corruption); distinctive `wisp-` prefix minimizes collision |
</threat_model>
