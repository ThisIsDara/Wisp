```cpp
namespace WinLaunch {
enum class LaunchResult { Launched, CancelledByUser, Failed };
// Classic app: ShellExecuteEx(verb open|runas) on targetPath with arguments and
// lpDirectory = QFileInfo(targetPath).absolutePath(). elevated=true → runas +
// SEE_MASK_NOCLOSEPROCESS (wait on the process handle). UAC-cancel → SE_ERR_ACCESSDENIED
// / immediate handle close → CancelledByUser (quiet — D-11). targetPath must be a
// file path (AppEntry from the 03-02 enumerator is already resolved).
LaunchResult launchClassic(const AppEntry &entry, bool elevated);
// UWP: CoCreateInstance(CLSID_ApplicationActivationManager) →
// ActivateApplication(entry.aumid.toStdWString().c_str(), nullptr, AO_NONE, &pid).
// Failure HRESULT → Failed (never crash; RESEARCH unknowns). NO runas variant exists —
// elevation refusal happens in LaunchController BEFORE this is called.
LaunchResult launchUwp(const AppEntry &entry);
}
```

```cpp
    void adminRequestRefused(const QString &displayName); // transient hint (D-11), 03-05 QML shows it
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keystroke → process creation | User input (Enter / Ctrl+Shift+Enter on a selected row) crosses into launching arbitrary programs, including elevated |
| .lnk metadata → ShellExecuteEx args | Path/arguments from user-writable Start Menu .lnk files flow into process creation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04-01 | S | ShellExecuteEx target | mitigate | Launch ONLY via resolved AppEntry (from enumeration); elevation ONLY on explicit Ctrl+Shift+Enter (D-11); UWP entries structurally cannot elevate (refused before any call — Test 2) |
| T-03-04-02 | I | arguments injection | accept | Args come from the user's own .lnk files (same-privilege metadata, RESEARCH §1); ShellExecuteEx passes lpParameters verbatim to the target process — no shell interpolation (documented MS behavior); the user owns the shortcuts |
| T-03-04-03 | D | wrong-app launch (shift) | mitigate | D-12 frozen snapshot at keypress (Test 1): a re-query between keypress and call cannot change the target |
| T-03-04-04 | D | UAC-cancel error spam | mitigate | CancelledByUser classified explicitly (ERROR_CANCELLED / SE_ERR_ACCESSDENIED) → silent return, zero signals (Test 4) |
| T-03-04-05 | E | UWP activation failure | mitigate | ActivateApplication HRESULT wrapped as launchFailed (never crash; RESEARCH unknowns) — Test 5 |
| T-03-04-06 | E | elevation of UWP bridge .lnk | accept | Bridge .lnk resolves to shell:AppsFolder aliases (RESEARCH unknowns); runas on such a target either works (host exe) or returns CancelledByUser/Failed — treated as normal outcomes; refusal covers true UWP entries |
