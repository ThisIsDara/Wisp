<objective>
Create `AppCatalog` — the in-memory, worker-thread-built, deduped app list that every search and launch flows through. It owns the threading contract (D-08: build at startup off the hotkey path, 10-minute age refresh, silent atomic swap), the storage decision (D-09: in-memory, no SQLite), and the dedupe rule (D-10: .lnk wins on exact case-insensitive name collision) — with injectable scanners so `tst_catalog` proves all three policies without a live Windows session.

**Purpose:** The hotkey path must stay &lt;100ms to first show (PITFALLS #14, criterion 5) — the catalog removes the scan from that path entirely. The silent-swap design means the UI never waits on a rebuild. Dedupe and sort are ROADMAP criterion-2 guarantees that must hold regardless of machine state — injected-scanner tests make them deterministic.

**Output:** AppCatalog with worker/age/swap/dedupe policy + passing tst_catalog; 03-04 (launch) and 03-05 (main.cpp + model) consume it.
</objective>

```cpp
class AppCatalog : public QObject {
    Q_OBJECT
public:
    explicit AppCatalog(QObject *parent = nullptr);

    // Scanner injection (03-05 wires real Win enumerators; tests inject fakes).
    // The SAME std::function mechanism as LauncherController::setFullscreenGuard
    // (PATTERNS §2). Default: real WinStartMenuEnumerator::scanStartMenu +
    // WinUwpEnumerator::scanUwpApps via a default-scanners internal factory.
    using Scanner = std::function<QVector<AppEntry>()>;
    void setScanners(std::vector<Scanner> scanners);
    void setRefreshInterval(std::chrono::milliseconds interval); // test hook; default 10 min

    // Kick the first build on the worker thread (called once at startup in
    // main.cpp — NEVER from the hotkey path; D-08).
    void start();

    // Checks build age; rebuilds on the worker ONLY if older than the interval.
    // Cheapest possible call — safe on the hotkey/show path (D-08).
    void ensureFresh();

    // Immutable snapshot of the current catalog. Returning by value keeps the
    // swap atomic: callers see ONE consistent version (silent swap, D-08).
    // UI thread-safe (cheap copy of implicitly-shared QVector).
    QVector<AppEntry> entries() const;

signals:
    void refreshed();   // emitted after a swap completes (03-05 wires → ResultsModel::setEntries)
    void buildFailed(int errorCount); // scan error padding (log-level; UI ignores)

private:
    // worker: runs scanners (each must be called on a COM-initialized thread —
    // THIS worker owns init/uninit per PITFALLS #3), dedupes (D-10), sorts
    // alphabetical case-insensitive (D-03), swaps when done.
};
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker thread → live catalog | Scanned app metadata crosses the thread boundary into the UI-readable snapshot |
| scanner fns | Untrusted-in-principle lambdas (production: OS metadata; tests: fakes) run on the worker |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | D | silent swap | mitigate | Atomic snapshot reads (copy under lock / single shared QVector swap); Test 4 proves readers never see partial lists during a blocking rebuild |
| T-03-03-02 | D | concurrent rebuilds | mitigate | Single-flight flag: overlapping start()/ensureFresh() calls coalesce; no double-build, no double-refreshed emission (Test 3/4 assert one refresh per swap) |
| T-03-03-03 | I | scanner exception | mitigate | Worker lambda try/catch per scanner; buildFailed(errorCount) signal; previous snapshot preserved (Test 5) |
| T-03-03-04 | S | dedupe collision abuse | mitigate | Exact case-insensitive full-name equality only (toCaseFolded keys); .lnk always preferred, UWP suppressed (D-10, Test 1); no fuzzy matching |
| T-03-03-05 | E | COM apartment leakage | mitigate | init_apartment/uninit scoped to the worker batch (RESEARCH §2, PITFALLS #3); scanners never called off-worker except tests with their own inits |
</threat_model>
