## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Start Menu .lnk files → parser | User-writable user-profile files are read and parsed; all-users folder contains machine-admin-written files |
| PackageManager metadata → AppEntry | OS-provided app metadata crosses into the catalog |
| COM/WinRT apartment | Enumeration runs on a worker thread with per-thread COM init (PITFALLS #3) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | D | .lnk parser | mitigate | Per-link exception/HRESULT guard + continue (Task 1 step 5/6); garbage fixture test proves no crash; scan never aborts mid-batch |
| T-03-02-02 | S | .lnk spoofed metadata | accept | Same-user Start Menu; display text only (no execution here — 03-04 validates launch); no privilege boundary crossed |
| T-03-02-03 | I | UWP duplicate/framework entries | mitigate | isSkippable triple filter unit-tested (framework, non-launchable, unnamed) — criterion-2 guarantee independent of machine state |
| T-03-02-04 | S | AUMID injection | mitigate | AUMID built ONLY from PackageFamilyName+AppId via buildAumid (never parsed from user input); unit-tested exact format |
| T-03-02-05 | E | COM apartment misuse | mitigate | Documented contract: scanners require pre-initialized apartment; catalog worker (03-03) owns init/uninit; PITFALLS #3 rule (same thread creates + uses objects) |
