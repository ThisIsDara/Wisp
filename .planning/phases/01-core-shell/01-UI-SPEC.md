# Phase 1 — UI Design Contract (Core Shell)

> Visual and interaction contract for the launcher **shell**: frameless centered widget, dark surface, scale+fade open/close animation, DPI correctness, compliance seeds. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Qt adaptation note:** this is a Qt6/QML desktop app, not web. Tokens are logical pixels (Qt PMv2 handles DPI — never hardcode physical pixels), typography is Segoe UI (Windows-native), colors are hex. The "component library" is project-authored QML. Registry Safety is N/A (no component registries in Qt).

## Typography

Family: `Segoe UI Variable` → fallback `Segoe UI`. Weights: exactly two — **regular (400)** and **semibold (600)**. All tokens are `font.pixelSize` logical px, single-line UI (elide via `elide: Text.ElideRight`), line-height ratio 1.2.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Query | 18 | 400 | 1.2 | Search field text (Phase 3) — the largest text in the product |
| Title | 15 | 400 | 1.2 | Result titles (Phase 3) |
| Subtitle | 12 | 400 | 1.2 | Paths/subtitles, status hints (Phase 3+); color `textSecondary` |
| Keycap | 12 | 600 | 1.2 | Keyboard-hint labels (Phase 3+), e.g. "Enter", "Esc" |

Phase 1 renders no text content — the typography tokens ship inside `Theme.qml` now so Phase 3 cannot diverge. Selection states may use 600 weight on Title (no size change — never bold-italic remeasure layout). Line-height 1.4 is reserved for any future wrapped text; none exists in v1.

## Color

60/30/10 split over the launcher surface (all hex, defined in `Theme.qml`):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1E1E1E` | **Window surface** (the shell itself). Sleek near-black, proven dark-UI surface (VS Code dark). |
| Secondary (30%) | `#2D2D30` | Inset wells (search-field well, Phase 3), scrollbar track, any card/inset surface |
| Border | `#3F3F46` | 1px surface hairline — separates the surface from any desktop; required for dark-on-dark visibility |
| Accent (10%) | `#0078D4` | **Selection/row highlight background** (Phase 3), caret, focus ring. Windows-native accent blue — safe, native-feeling default; user-replaceable via Phase 6 picker. |
| Accent light (text) | `#58A6FF` | Accent-colored **text on the dark surface**: match-highlight characters (Phase 5, LAUN-06), selected-row subtitle text. (Raw `#0078D4` fails 4.5:1 as text on `#1E1E1E` — never use it for text.) |
| Text primary | `#F5F5F5` | Primary text on surface — contrast ≈ 15.2:1 ✓ |
| Text secondary | `#A0A0A0` | Subtitles, hints — contrast ≈ 6.3:1 ✓ |
| Destructive | none | No destructive actions in this phase or its direct consumers (launch/close are non-destructive). Declared "none" — do not introduce red anywhere. |

Accent is reserved for EXACTLY: selected-result highlight background, focused search-field caret + focus ring, and match-highlight text (via `accentLight`). It is **not** for: buttons, borders, background tints, headers, or any bulk fill. Selection rule: selected row background = `#0078D4` at 100% with white title text (white on `#0078D4` ≈ 4.7:1 ✓); hover (Phase 3) uses `#2D2D30` — never accent.

Shadows: static, pre-rendered soft shadow under the surface (black, ~45% alpha, ~16px spread, blur radius fixed). Must be a static `Image`/single shader pass — **no blur in the animated subtree** (perf: PITFALLS #12).

## Animation & Motion Contract (VISU-01 — the phase's core visual deliverable)

| Property | Open | Close | Notes |
|----------|------|-------|-------|
| Duration | **150 ms** | **140 ms** | Within the mandated 150–200ms; close slightly faster = snappier exit |
| Opacity | 0 → 1 | 1 → 0 | Parallel with scale |
| Scale | 0.96 → 1.0 | 1.0 → 0.96 | Origin: center; subtle zoom, never dramatic |
| Easing | `OutCubic` | `InCubic` | Fast-start/soft-land = "smooth"; close accelerates = crisp |
| Frame budget | 60fps minimum (≤16.7ms/frame) | same | QML `ParallelAnimation` on `opacity` + `transform: Scale` only — GPU-composited, no layout, no effects |

Hard rules (executor + checker):

1. **Animate only `opacity` and `Scale` transform.** No animating of `width/height/x/y`, no blur/`MultiEffect` inside the animated subtree, no font/metrics changes mid-animation.
2. **Close sequence:** play the 140ms close animation to completion, then `window.hide()` in the animation's `onCompleted`. Never hide mid-animation (visible pop).
3. **Open latency vs. animation are separate budgets:** the window must be **visible and animating within 100ms** of the show request (first-show <100ms budget, SUMMARY §Implications); the 150ms animation is a *visual polish* layered on top, never a gate on input readiness. (Typing arrives Phase 2 — the open animation must not be wired to block or delay anything.)
4. The animated subtree is the entire surface including its shadow (scale applies to the composited layer). One QML layer; if `layer.enabled` is used, keep it static between frames (disable re-render during animation if it costs frames).
5. Demo trigger this phase: **Escape** plays the close animation → hide. (Real dismissal — launch, click-away — is Phase 2; HOTK-03's "launch dismissal is instant, no animation wait" governs there, not here.)
6. Do not animate on first paint before the window is shown; start the open animation from `onVisibleChanged`.

## Geometry & Window Contract

| Property | Value | Rationale |
|----------|-------|-----------|
| Window flags | `Qt.Tool \| Qt.FramelessWindowHint` | **Locked** (STATE.md): Tool = no taskbar button; Frameless = no chrome. Never `Qt::Popup` (swallows dismissal click, breaks IME). |
| Size | **640 × 400 logical px, fixed** (no resize) | PowerToys Run 600×330 / Ulauncher 640 class. Height is the Phase 3 content budget: ~52px search field + 7 × 44px rows + 2 × 16px padding = 400. Locks the visual foundation now so Phase 3 never re-specifies geometry. |
| Position | Centered on **primary screen** `availableGeometry().center()` (respects taskbar), logical px via Qt `QScreen` — never `GetSystemMetrics`, never hardcoded pixels | PITFALLS #7 |
| Window background | `color: "transparent"` + C++ `Qt::WA_TranslucentBackground` on the QQuickWindow | Required for rounded corners on Windows (DWM does not clip Qt windows). |
| Corner radius | 12px on the surface `Rectangle` (clip children) | Sleek modern dark-launcher radius. |
| Surface border | 1px `#3F3F46` | Dark-on-dark separation. |
| Shadow | Static soft shadow, ~16px, black 45%, pre-rendered (see Color) | Depth without per-frame blur cost. |
| Resize | Disabled (fixed 640×400) | Keyboard-first popover; dynamic height is churn, defer forever. |
| Backdrop blur / acrylic | **NOT in this phase** (VISU-04 v2, deferred; solid `#1E1E1E` surface only) | Locked in STATE.md. Graceful-degradation target = this solid surface. |
| DPI | Qt PMv2 default — **never call `SetProcessDpiAwareness*` or any manual DPI API** anywhere (incl. main.cpp). All sizes/fonts logical. Accept 1px hairline at fractional dpr (draw 1 logical px; crispness verified on 100% + 150% mixed setup). | Locked (STATE.md, PITFALLS #7) |

## Interaction Contract (Phase 1 scope only)

| Interaction | Contract |
|-------------|----------|
| Show (demo) | App launch shows the window immediately, centered, open animation plays |
| Dismiss (demo) | **Escape** → close animation → hide (above). This is the only dismissal this phase |
| Focus | Window is activatable (Phase 1 demo runs foreground). Focus/activation sequencing, hotkey, click-away, fullscreen guard = Phase 2 — do not build any activation machinery now, but **do not add code that would fight it later** (no `Qt.Popup`, no `WS_EX_NOACTIVATE`, no global hooks) |
| Resize | None (fixed geometry) |
| Drag | Not draggable (launcher semantics; backdrop lag concerns in STACK.md are moot) |
| Perf guard | First show → first painted frame < 100ms; animation holds 60fps (frame-time logging in debug build, drop-counting) |
