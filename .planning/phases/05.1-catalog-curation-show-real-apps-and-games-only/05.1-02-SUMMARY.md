## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] dedupeLnkOverUwp silently dropped Source::File rows**
- **Found during:** task 2 GREEN gate (fileRowsNeverCurated_CUR04 failing: entries.size() == 1, expected 2)
- **Issue:** `dedupeLnkOverUwp` only passes Lnk and UWP entries through; a File row fed via scanner was discarded before `markCurated` ever ran. The plan's CUR-04 contract (must-have truth: "Source::File rows are never marked hidden"; test asserts size==2 with the File row visible) is unsatisfiable through the real pipeline — markCurated's File guard would be dead code. Production today only feeds Lnk/UWP scanners (main.cpp), so the drop was latent, but the plan's own fixture exposes it.
- **Fix:** Added a File-row passthrough loop at the end of `dedupeLnkOverUwp` with a comment documenting that D-10 collision logic is Lnk-over-UWP only and the CUR-04 guard must stay reachable. No collision logic for File rows (D-10 scope unchanged).
- **Files modified:** src/core/AppCatalog.cpp
