### `src/core/CurationRules.h/.cpp` (NEW — pure matcher, transform)

**Analog:** anonymous-namespace pure functions in `AppCatalog.cpp` (dedupeLnkOverUwp lines 20-40, sortAlphabetical 44-49) — namespace-scope function, no Qt object, no state, unit-testable.

**Header shape:**
```cpp
#pragma once
#include "core/AppEntry.h"

// Pure default-rule matcher (research Pattern 1) — one entry point, no Qt
// object needed. NOT a ranker: FuzzyMatcher is a subsequence ladder and must
// NOT be reused for semantic blocklist matching (research Anti-Patterns).
namespace CurationRules {
bool matches(const AppEntry &e);   // true when a DEFAULT rule hides the entry
}
```

**Implementation shape:** case-insensitive checks only (no regex, no DSL — research Don't Hand-Roll):
- `displayName.toCaseFolded().startsWith("uninstall")` — bucket 1 (~25 uninstallers)
- word-boundary containment for "release notes", "what is new", "check for updates", "license", "help", "configure" — bucket 4 (~80 installer cruft)
- `targetPath.toCaseFolded().contains("\\qt\\")` etc. — bucket 2 (~50 toolchains); skip for UWP rows (empty targetPath)
- system-util name/exe lists — bucket 3 (~45)
- MUST NOT match: "windows terminal", "microsoft store", "visual studio code" (research Pitfall 4 — conservative list, per-bucket documented)

**Testing:** fixtures mirror the measured buckets via `lnkEntry(name, path)` / `uwpEntry(name)` helpers (tst_catalog.cpp:20-37 style).

**Marking step — anonymous-namespace pure function next to dedupe (AppCatalog.cpp:13-51 style):**
```cpp
// Pure marking (research Pattern 1): NEVER removes entries — hidden stays in
// the snapshot so Show-hidden/Unhide work without a rebuild. Identity: Lnk →
// targetPath, UWP → aumid. shownIds override wins over rules. File rows never
// curated (escape-hatch guard — locked constraint, CUR-04).
void markCurated(QVector<AppEntry> &entries, const CurationData &data)
{
    for (AppEntry &e : entries) {
        if (e.source == AppEntry::Source::File)
            continue;                       // added executables are File source
        const QString id = e.targetPath.isEmpty() ? e.aumid : e.targetPath;
        if (data.shownIds.contains(id))
            continue;                       // explicit user override beats rules
        e.hidden = data.hiddenIds.contains(id) || CurationRules::matches(e);
    }
}
```

**Pipeline insertion — STRICTLY after dedupe, before sort (AppCatalog.cpp:157-163):**
```cpp
    // Policy pipeline: dedupe (D-10) → curation mark (05.1) → sort (D-03) → swap (D-08 silent).
    QVector<AppEntry> next = dedupeLnkOverUwp(result.entries);
    markCurated(next, m_curationSource ? m_curationSource() : CurationData{}); // NEW
    sortAlphabetical(next);
    {
        QMutexLocker locker(&m_snapshotMutex);
        m_snapshot = std::move(next);
    }
```
Ordering is load-bearing (research Pitfall 1): marking before dedupe would resurrect the suppressed UWP twin of a hidden .lnk. Runs on the UI thread (watcher completion) — value-copy QSet read, no mutex (SettingsStore precedent). Never inside the worker lambda (WR-01).
