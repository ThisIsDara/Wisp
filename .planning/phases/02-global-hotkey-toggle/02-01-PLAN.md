    - #include <windows.h>, <QAbstractNativeEventFilter>, <QDebug>
    - registerCombo: `return RegisterHotKey(nullptr, id, mods, vk) != 0;`
    - nativeEventFilter(const QByteArray &eventType, void *message, qintptr *result):
      if (eventType == "windows_dispatcher_MSG") { auto *msg = static_cast<MSG*>(message);

    Do NOT use QHotkey. Do NOT use QWidget::nativeEvent (Qt5 API, silent in Qt6 — RESEARCH.md §1).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS hotkey space | Global hotkey registration touches a shared OS resource; a foreign app can hold the combo |
| settings file | %APPDATA% INI — writable by the user only, but a requirement (D-02.5) for clean-machine behavior |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | D | RegisterHotKey combo | mitigate | RegisterHotKey conflict → registrationFailed signal; caller must surface (HOTK-02 contract; never silent) |
| T-02-01-02 | S | WM_HOTKEY spoofing | accept | OS-gated (only the registered thread receives real WM_HOTKEY); single unsigned id space 0x0000–0xBFFF |
| T-02-01-03 | I | %APPDATA% INI parse | mitigate | HotkeyManager validates sequence before registering; F12/modifier-only rejected; QSettings defaults on missing keys; no execution from the file |
| T-02-01-04 | E | settings file path | accept | Per-user AppData scoped; no privileged data; test-path override keeps temp dirs out of the real INI (D-02.5 testability) |
</threat_model>
