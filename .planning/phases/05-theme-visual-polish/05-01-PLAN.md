<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted .lnk content → extraction seam | iconRef/iconPath strings originate in Start Menu .lnk files (user-writable location). parseKey + COM extraction consume them. |
| untrusted INI content | (accent handled in 05-03) — n/a here. |
| UWP package store files → WinRT seam | AppxManifest.xml parsed from InstalledLocation; packages are OS-signed but parse defensively. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | WinIconExtractor::extract (path from .lnk may point to network share / arbitrary file) | mitigate | Extraction reads the icon BITMAP only — GetImage never executes the target. Runs exclusively on Qt's provider thread (never UI thread, STACK HIGH rule). Any HRESULT failure → qWarning + null QImage (D-16). No shell verb, no process spawn anywhere in this plan. |
| T-05-02 | DoS | Provider-thread extraction on slow UNC/remote paths | mitigate | Confined to the dedicated provider thread (UI stays responsive); sub-10ms typical for local paths (D-03); failures return null immediately (never retried in a loop by this plan); bounded LRU cache in 05-02 caps memory (D-03 ~8MB). Residual: a pathological share could stall the provider thread — accepted (single worker, icons re-requested lazily). |
| T-05-03 | Tampering | WinUwpLogo AppxManifest.xml parsing | accept | Packages come from the OS-signed store (package identity checked via GetPackageByFullName). QXmlStreamReader does not resolve external entities → no XXE. Malformed XML → QXmlStreamReader error → null QImage. |
| T-05-04 | Information disclosure | None — extraction produces local bitmaps only; no secrets, no network egress in this plan | accept | No PII, no credentials, no remote calls. |
| T-05-05 | Spoofing | iconRef format confusion ("uwp:" vs "path:" vs ";index") | mitigate | parseKey rules are exact and unit-tested (tst_icons); invalid keys → isValid() false → null QImage, never misinterpreted as a different kind. |
</threat_model>
