# wisp v0.1.0 — First light

*Neat, sweet, and smooth. Press `Alt+Space` and your app is already open.*

Welcome to the first release of wisp. This release brings the whole idea to
life: a global hotkey, fuzzy search that knows your apps and files, and an
open/close animation that feels instant.

- **Instant** — hotkey to launch in under a second, 60fps animation
- **Fuzzy everything** — Start Menu apps, Store/UWP apps, indexed files, and
  executables you added yourself, in one ranked list
- **Yours to curate** — hide any entry, add any executable, pick your accent

## 🚀 Features

- Global `Alt+Space` hotkey — configurable in Settings
- Fuzzy matching across Start Menu apps, UWP/Store apps, and Windows
  Search–indexed files, with match highlighting
- **Add executable…** from the tray — bring any program into the launcher
- Entry curation: `Ctrl+H` hides, `Ctrl+Shift+H` reveals hidden entries
- Acrylic backdrop on Windows 11, blur fallback on Windows 10
- Tray icon with Settings: hotkey, accent color, autostart
- Per-user installer — no admin rights, VC++ runtime handled automatically
- Single instance — the hotkey always finds the one launcher

## 🗺️ Roadmap

- No plugins, calculator, or command modes in v0.1 — wisp stays a focused
  launcher; feature requests are welcome in Issues
- File search matches names, not full-text contents
- Code-signed releases: SignPath Foundation signing is in progress — see
  the code signing policy in the repository

## 📦 Install

Download **wisp-setup.exe** below, run it, and press `Alt+Space` anywhere.
If SmartScreen asks, choose *More info → Run anyway* (signing is on the
roadmap above) — and only trust downloads from this release page.
