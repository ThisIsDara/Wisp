## wisp v0.1.3

The instant app launcher for Windows 10/11. Press Alt+Space anywhere, type a few letters, and launch apps, Store apps, and files.

### What's new

- Automatic updates - wisp checks once a day for a new version and tells you when one is out. Download and install it right from the notification, no reinstalling
- New "Updates" section in settings - check manually anytime, or turn on automatic installs (off by default) and wisp handles everything itself, including restarting when it's done
- Update downloads are checksum-verified before anything gets installed
- Fixed favorited apps disappearing from the Favorites tab when they were also hidden
- The scrollbar thumb now travels all the way to the bottom of the list

### Install

Download and run [wisp-setup.exe](https://github.com/ThisIsDara/Wisp/releases/download/v0.1.3/wisp-setup.exe)
