## wisp v0.1.7

The instant app launcher for Windows 10/11. Press Alt+Space anywhere, type a few letters, and launch apps, Store apps, and files.

### What's new

- Keyboard shortcuts reference - a new "Show shortcuts" button in Settings opens a themed window listing every key wisp understands, so there's no more guessing
- Settings refresh - the Scan locations and Updates sections got headers on top with breathing room, and every action button (Scan now, Check for updates, Download now, Add folder) now lines up on the right with its text on the left
- Roomier folder list - scan folders sit in taller rows with real clearance around the Remove buttons and the separators, and the window shrank to fit so there's no dead space at the bottom
- Destructive Remove buttons - removing a scan folder now lights up red on hover, so it's obvious the action deletes something
