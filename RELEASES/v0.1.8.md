## wisp v0.1.8

The instant app launcher for Windows 10/11. Press Alt+Space anywhere, type a few letters, and launch apps, Store apps, and files.

### What's new

- Right-click "Open file location" — right-click any app or file result and jump straight to the real file or shortcut target in Explorer, instead of hunting for it yourself
- Polished context menu — the right-click menu resizes to fit its longest label so nothing gets clipped, and clicking anywhere (including window corners, tabs, and footer) dismisses it
- Cleaner Favorites tab — "Hide" and "Show hidden" are hidden in the Favorites tab, since they can't do anything there

### Install
