## wisp v0.1.9.1

The instant app launcher for Windows 10/11. Press Alt+Space anywhere, type a few letters, and launch apps, Store apps, and files.

### What's new

- Your list is there right after updating - if v0.1.9 left you with an empty list because wisp couldn't read your old index, this refreshes it automatically the first time you launch. Nothing to click, and it only happens once
- Folder chips get breathing room - the scanned folders now sit clear of the "Folders wisp searches for files and folders" line instead of crowding it

### Install

Download and run [wisp-setup.exe](https://github.com/ThisIsDara/Wisp/releases/download/v0.1.9.1/wisp-setup.exe)
