## wisp v0.1.4

The instant app launcher for Windows 10/11. Press Alt+Space anywhere, type a few letters, and launch apps, Store apps, and files.

### What's new

- Calculator - type any math like `2+2`, `12*34` or `2^8` and see the answer right at the top. Press Enter to copy the result, the launcher stays open so you can keep calculating
- Smarter ranking - apps you launch often and recently now bubble up in results
- Fixed installer error when updating while wisp is still running (no more "Error opening file for writing: Qt6QmlModels.dll")

### Install

Download and run [wisp-setup.exe](https://github.com/ThisIsDara/Wisp/releases/download/v0.1.4/wisp-setup.exe)
